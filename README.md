Python Calculator 🧮

Project over-view 
A simple command-line calculator built with Python. The program allows users to perform basic arithmetic operations while demonstrating input validation and exception handling. 

🎯Purpose 

This project was created to practice Python fundamentals with a focus on exception handling, input validation and creating an interactive command-line program.

Features 
- Addition ➕, Subtraction ➖, Multiplication ✖️, Division➗
- User-friendly operation menu
- Input validation for numeric values 
- Handles invalid inputs by using ValueError 
- Handles division by zero using ZeroDivisionError
- Uses try, except, else, and finally for exception handling 
- Allows users to perform multiple calculations or exit the program
- Provides a message indicating whether the operation was successful or unsuccessful. 

How it works 
1. The user selects an operation from the menu: 
    * Add, Subtract, Multiply, Divide 
2. The user enters two numbers.
3. The program validates the inputs.
4. The selected calculation is performed.
5. Errors such as invalid numbers or division by zero are handled appropriately.
6. The program asks whether the user would like to perform another calculation or exit.
